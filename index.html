About this website

Epilepsy is a brain disorder where people have repeated seizures. In focal epilepsy, the seizures start in one specific area of the brain, for example the temporal or the frontal lobe. It is the most common type of epilepsy in adults, and it has many subtypes.

Some subtypes are caused by changes in specific genes, and different subtypes are treated with different drugs. On this website you can see which genes and which drugs are linked to each subtype, using data from Wikidata.

I chose this topic because my bachelor thesis is also about epilepsy, so I wanted to learn more about the genetic side and the treatments.

Research question

Which genes and which drugs are linked to focal epilepsy and its subtypes, and which of them are shared between subtypes?

What I found

In the Wikidata data, no gene is shared between subtypes: every gene is linked to only one subtype. Drugs are different. Lamotrigine, carbamazepine and levetiracetam are each linked to more than one subtype. Levetiracetam is called "(S)-etiracetam" in Wikidata, which is why it has a different name in the tables.

How to use this website

Use the menu at the top of the page to move between the pages. The data is loaded live from Wikidata every time you open a page, so it can take a few seconds to appear.

  • Genes: a bar chart showing how many genes are linked to each subtype, with a table of all the genes below it. Hover over a bar to highlight it.
  • Drugs: the same for drugs, showing how many drugs are used to treat each subtype.
  • Network: all subtypes, genes and drugs in one picture. Hover over a circle to see its name and the lines connected to it, and drag circles to move them around. A drug with lines to more than one subtype is shared between those subtypes.
